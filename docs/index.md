# VM RSync

Bidirectional file synchronization between a local workspace tree and remote machines, driven by rsync over SSH.

## Documentation

| English | Português |
|---------|-----------|
| [User Guide](GUIDE.md) | [Guia de Uso](GUIDE-PT.md) |

## Quick install

```bash
git clone https://github.com/carlosrabelo/vmrsync.git
cd vmrsync
make build
make install-system
sudo vmrsync completion bash
```
